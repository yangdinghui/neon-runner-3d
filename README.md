# 霓虹奔跑者 · NEON RUNNER 3D

🎮 **在线试玩：<https://yangdinghui.github.io/neon-runner-3d/>**

一个第三人称 3D 霓虹跑酷小游戏：无尽赛道、键盘操作、粒子拖尾、程序化音效、本地分数排行榜。
画风是「浅色小清新卡通 × 赛博朋克霓虹」—— 底色白净柔和，霓虹只用在光带、粒子与描边上。

零依赖、零构建：**双击 `index.html` 就能玩**（three.js 已内置在 `vendor/`，贴图与音效全部代码生成，完全离线可用）。桌面键盘、手机触屏都能玩。

---

## 快速开始

```bash
# 方式一：直接打开（最省事）
open index.html

# 方式二：本地服务器（推荐用 Chrome / Edge，localStorage 才能持久保存排行榜）
python3 -m http.server 8777
# 然后浏览器打开 http://127.0.0.1:8777/index.html
```

> 首次按键/点击才会出声，这是浏览器的自动播放策略，不是 bug。

## 操作

### 电脑（键盘）

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `A` `D` | 左右横移（灵动跑位，不是固定三车道） |
| `空格` / `W` / `↑` | 跳跃；空中再按一次 = **二段跳** |
| `↓` / `S` / `Shift` | 地面滑铲（钻过横杆）；空中按下 = 快速飞坠 |
| `Esc` / `P` | 暂停 / 继续 |
| `R` | 重新开始 |
| `M` | 静音 |
| `→` `Enter` | 菜单开始 / 结算时再来一局 |

### 手机 / 平板（触屏，双拇指）

| 操作 | 作用 |
| --- | --- |
| **左手**：按住屏幕左下角摇杆区域左右拖动 | 相对当前位置横向跑位，拖动幅度 = 移动距离，松手就停在原地 |
| **右手**：右下角「跳」按钮 | 跳跃；**快速连点两次 = 二段跳** |
| **右手**：右下角「滑」按钮 | 按住 = 滑铲钻横杆；在空中按住 = 快速飞坠 |
| 右上角 ❚❚ / 🔊 | 暂停 / 静音 |

触屏是「跟手拖动」而不是虚拟按键长按，转向带缓入缓出，越推越快、接近目标自动收敛。手机建议**横屏**（竖屏也能玩，会自动拉大视角并提示横屏）。点击「开始奔跑」时会自动尝试进入全屏。

## 玩法

- **躲**：低矮霓虹方块要**跳**；全宽横杆要**滑铲**；高墙要**左右闪**。撞到会掉一个护盾，并且速度会短暂下降。
- **吃**：能量球 +12 分，金色大球 +60 分；在 2.7 秒内连续吃到会叠**连击倍率**（最高 x8，分数按倍率乘算）。
- **冲**：速度会随距离不断爬升（19 → 47 u/s），越往后障碍越密、套路越花。
- **护盾**：初始 3 个，每 800 米补一个（满了则额外加 120 分）。护盾归零即游戏结束。
- **排行榜**：结算时若进入前 10 会请你留下名字，成绩存在浏览器本地（`localStorage`），主菜单与结算页都能看到。

## 实现要点

- **无尽赛道不移动玩家**：世界向 +z 滚动，玩家 z 恒为 0；所有内容用「赛道里程 `s`」记录，渲染时 `z = D - s`（`D` = 已跑里程），既不会浮点漂移，回收也只是改一下 `s`。
- **关卡在雾外生成**：雾 60→230，生成线在 240 处，所以永远看不到障碍突然弹出；开局先 `prefill()` 铺好前 150 米当起跑缓冲。
- **浅色背景不用 additive 混合**：加法混合在白底上等于消失，所以粒子/拖尾都用高饱和色的普通透明混合，靠颜色而不是亮度发光。
- **卡通观感**：`MeshStandardMaterial` 柔和漫反射 + 半球光 + 平行光软阴影 + 贴地的柔和接触阴影球。
- **音效全程序化**：振荡器/噪声 + 包络合成跳跃、落地、滑铲、拾取（音高随连击上行）、受击、结算；BGM 是 D 大调五声音阶的 16 步循环，速度、踩镲密度、和声层随游戏强度变化。
- **帧率无关**：所有运动用 `dt` 指数平滑（`damp`）与积分，掉帧不会改变手感。
- **低帧率防穿透**：障碍一帧内会向后滚 `speed × dt`，高速低帧时单帧位移可达 2.4 个单位，所以碰撞用「扫掠区间」而不是只测当前位置，否则 30fps 的手机上会直接穿过障碍。
- **移动端分级**：自动识别机型选画质档（`high / mobile / low`），手机端降像素比（1.5）、砍阴影分辨率、去掉赛道两侧的大面积透明光带、减少云与远景数量——移动端瓶颈是填充率而不是面数。
- **窄屏自适应视角**：竖屏时按水平视角反算垂直 FOV（上限 88°）并压低镜头，否则竖屏只能看到赛道中间一条缝。

## 想改点什么

| 想要的效果 | 改哪里 |
| --- | --- |
| 更难 / 更简单 | `config.js` → `rules.shields`、`speed.max`、`speed.accel`，或 `world.js` → `_planNext()` 里的 `gapT` 间隔 |
| 跑得更快 | `config.js` → `speed.base` / `speed.max` |
| 跳跃手感 | `config.js` → `player.jumpVel`（跳得更高）、`player.gravity`（下落更利落） |
| 换配色 | `config.js` → `PAL`（`neonCyan` / `neonPink` 等） |
| 换角色外形 | `player.js` → `_build()`（都是基础几何体拼的，随便加） |
| 触屏转向灵敏度 | `config.js` → `touch.dragGain`（越大越灵敏）、`touch.maxDragPx`（摇杆圆点最大位移） |
| 触屏按钮大小 / 位置 | `css/style.css` → `.touch-btn`、`.pad-steer` |
| 画质档位 | `config.js` → `QUALITY_PRESETS` |
| 改粒子量 | `config.js` → `fx.maxParticles`、`fx.trailPoints` |

调试时在网址后面加 `?debug`，右下角会显示状态、帧率、drawcall、粒子数。还有个强制开关：`?q=high|mobile|low` 指定画质档、`?touch=1|0` 强制显示/隐藏触屏操作层（想在桌面模拟手机时很好用）。

## 说明与限制

- 需要 **WebGL**。桌面用键盘、手机/平板用触屏（双拇指：左手转向、右手跳滑）；键盘在触屏设备上也能用，两套输入可以同时生效。
- 手机建议横屏；竖屏可玩但视野更窄。iPhone 上 Safari 不支持网页全屏，所以「自动全屏」在 iOS 上不生效（Android / 桌面正常）。
- 排行榜存在**当前浏览器**的本地存储里，换浏览器或清缓存会丢；用 `file://` 直接打开时，Safari 可能禁止本地存储读取，此时排行榜不持久（换 Chrome 或起个本地服务器即可）。
- three.js r157 的 `vendor/three.min.js` 是官方 UMD 构建；官方从 r160 起移除了 UMD，所以这里锁在 r157。若该文件缺失，`index.html` 会自动回退到 CDN 加载。
